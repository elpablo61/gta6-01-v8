Crescent Bay — a top-down 2D open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Steal any car, outrun the police across a living coastal city, and run a 12-mission story arc with fixer contacts Mara and Dex: chases, shootouts, a police helicopter, weapon crates, a fixer garage with upgrades, three radio stations, and three save slots. Pure vanilla Canvas 2D and WebAudio — no libraries, no network, no external assets; the city is procedurally drawn from a fixed seed so every run plays the same streets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. WASD/arrows to move, mouse to aim, click to shoot, E to enter/exit a car, Shift to sprint, Space for handbrake, R to change radio station, 1/2/3 to switch weapons, Esc to pause.
